# 群聊工具集插件

AstrBot 群聊功能扩展插件，包含定时提醒、JM漫画下载、社区内容过滤、群管理。

## 功能列表

### 1. 定时提醒
自动在指定时间发送提醒消息到群。

| 时间 | 内容 |
|------|------|
| 周一 10:00 | 尘白每周商店/活动提醒 |
| 周二 10:00 | 拟想开启提醒 |
| 周四 10:00 | 尘白+整活v50 |
| 周日 21:00 | 尘白周末提醒 |
| 每天 22:55 | 群主催睡觉 |

### 2. JM漫画下载
发送漫画ID，自动下载并打包成PDF发送到群。

### 3. 社区内容过滤
自动过滤群内的黑子、串子等不当内容。

### 4. 群管理功能
- **进群自动禁言**：新成员进群后自动禁言，需发送UID截图验证
- **UID截图验证**：使用Windows OCR识别截图中的UID，自动解除禁言
- **敏感内容检测**：关键词匹配+AI二次判断，防止误判
- **违规处罚**：首次违规全体禁言12小时，累计3次永久禁言+踢出

## 指令列表

| 指令 | 说明 | 权限 |
|------|------|------|
| `/jm <ID>` | 下载指定ID的漫画 | 普通用户 |
| `/jmhelp` | JM下载帮助 | 普通用户 |
| `/listtask` | 查看所有定时任务 | 普通用户 |
| `/addtask <周几/每天> <HH:MM> <内容>` | 添加定时任务 | 普通用户 |
| `/deltask <编号>` | 删除定时任务 | 普通用户 |
| `/addfilter <关键词>` | 添加过滤词 | 管理员 |
| `/delfilter <关键词>` | 删除过滤词 | 管理员 |
| `/listfilter` | 查看过滤词列表 | 普通用户 |
| `/unlock <QQ号>` | 解除用户禁言 | 管理员 |
| `/violations` | 查看违规记录 | 管理员 |
| `/helpgroup` | 显示本帮助 | 普通用户 |

## 配置说明

在插件配置中可以调整以下选项：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_group_management` | bool | true | 启用群管理功能 |
| `enable_uid_verify` | bool | true | 启用UID截图验证 |
| `enable_content_moderation` | bool | true | 启用敏感内容检测 |
| `moderation_keywords` | list | [...] | 敏感内容关键词列表 |

## 使用示例

```
/jm 12345          # 下载漫画ID 12345
/addtask 周三 09:30 提醒开会   # 添加周三9:30的提醒
/deltask 1         # 删除第1个任务
/unlock 123456     # 解除用户123456的禁言
/violations        # 查看违规记录
```
