# 群聊工具集插件

AstrBot 群聊功能扩展插件，包含定时提醒、JM漫画下载、社区内容过滤。

## 功能列表

### 1. 定时提醒
自动在指定时间发送提醒消息到群。

| 时间 | 内容 |
|------|------|
| 周一 10:00 | 尘白每周商店/活动提醒 |
| 周二 10:00 | 拟想开启提醒 |
| 周四 10:00 | 尘白+整活v50 |
| 周日 21:00 | 尘白周末提醒 |
| 每天 22:55 | 群主催睡觉 |

### 2. JM漫画下载
发送漫画ID，自动下载并打包成PDF发送到群。

### 3. 社区内容过滤
自动过滤群内的黑子、串子等不当内容。

## 指令列表

| 指令 | 说明 |
|------|------|
| `/jm <ID>` | 下载指定ID的漫画 |
| `/jmhelp` | JM下载帮助 |
| `/listtask` | 查看所有定时任务 |
| `/addtask <周几/每天> <HH:MM> <内容>` | 添加定时任务 |
| `/deltask <编号>` | 删除定时任务 |
| `/addfilter <关键词>` | 添加过滤词 |
| `/delfilter <关键词>` | 删除过滤词 |
| `/listfilter` | 查看过滤词列表 |
| `/helpgroup` | 显示本帮助 |

## 使用示例

```
/jm 12345          # 下载漫画ID 12345
/addtask 周三 09:30 提醒开会   # 添加周三9:30的提醒
/deltask 1         # 删除第1个任务
/addfilter 黑子    # 添加过滤词
```
